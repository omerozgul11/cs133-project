## Project Description

This project analyzes housing data from California using information collected from the 1990 U.S. Census. The dataset includes geographic location, median income, number of rooms, population, and other housing characteristics. Our main goal is to identify which factors are most strongly related to median house value. We will use data analysis, visualizations, and machine learning methods to better understand and predict housing prices. The results will demonstrate how demographic and geographic characteristics influence real estate prices.

## Project Outline/Plan

### Interface Plan

We plan to present our findings through a Jupyter Notebook containing tables, charts, and written explanations. The interface will allow users to view the dataset, examine relationships between variables, and understand the results of our analysis. Our project will include scatter plots, histograms, box plots, a correlation heatmap, and visualizations showing housing prices by location. If time permits, we may create a simple interactive dashboard using Streamlit.

### Data Collection and Storage Plan

Written by Author #1

We will download the California Housing Prices dataset from Kaggle. The dataset will be stored as a CSV file in a local data folder during development. We will use Python and pandas to load the data, inspect the columns, identify missing values, and prepare the data for analysis. The original dataset will not be uploaded to GitHub if it is too large. The Kaggle link to the dataset is provided below so that the data source can be accessed.

### Data Analysis and Visualization Plan

Written by Author #2

We will calculate summary statistics and examine the structure of the dataset. We will analyze the relationship between median house value and variables such as median income, total rooms, population, longitude, and latitude. We will create histograms, scatter plots, box plots, and a correlation heatmap to identify important patterns and possible outliers. We will also build a regression model to predict median house value and evaluate it using mean absolute error, mean squared error, and R-squared. Finally, we will explain which variables appear to have the greatest relationship with housing prices.
